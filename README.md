# Weather Analytics & Forecast Decision Support System

A desktop-based weather analytics and forecast decision support application developed using Electron and JavaScript.

The application retrieves weather information from WeatherAPI and provides weather analysis, alerts, forecasts and activity recommendations to help users make decisions based on current and forecasted weather conditions.

## Features

- Search weather information for locations in Malaysia
- Real-time weather information using WeatherAPI
- Hourly weather forecast
- 3-day weather forecast
- Weather alert system
- Average temperature analysis
- Rain risk analysis
- Activity recommendations
- Activity Planner with CRUD functionality
- Local storage for activity data

## Technologies

- Electron
- JavaScript
- HTML
- CSS
- WeatherAPI
- LocalStorage
